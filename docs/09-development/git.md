# Git

## Branches

Estratégia inicial:

```text
main
 └── feat/*
 └── fix/*
 └── refactor/*
 └── docs/*
```

## Commits

Preferir mensagens claras e consistentes.

Exemplos:

```text
feat: add customer registration
fix: prevent cross-tenant vehicle access
docs: add command architecture
refactor: isolate device adapters
```

## Pull Requests

Mudanças relevantes devem ser revisadas antes de entrar em `main`.
