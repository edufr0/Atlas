# Aplicativo Administrativo

O aplicativo administrativo permitirá que funcionários autorizados operem a empresa pelo celular.

## Funcionalidades

- dashboard;
- clientes;
- veículos;
- dispositivos;
- SIM cards;
- comandos;
- cobrança;
- pagamentos;
- inadimplência;
- estoque;
- suporte;
- manutenção;
- instalações;
- auditoria.

O mesmo domínio de autorização usado pela API deve ser aplicado no aplicativo.
