# ADR-003 — Conta Única do Cliente

**Status:** Accepted

## Contexto

O MVP deve ser simples para o cliente final.

## Decisão

Inicialmente, cada cliente final terá uma única conta de acesso. Pessoas da mesma família podem compartilhar essa conta.

## Consequências

- menor complexidade;
- onboarding mais simples;
- autorização mais direta.

A arquitetura poderá evoluir para múltiplas contas no futuro sem alterar o conceito de Customer.
