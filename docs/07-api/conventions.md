# Convenções da API

## Princípios

- REST para operações de negócio quando apropriado;
- autenticação centralizada;
- autorização por tenant;
- respostas consistentes;
- validação de entrada;
- paginação;
- filtros;
- logs estruturados;
- versionamento da API.

## Erros

Erros devem possuir código estável e mensagem apropriada para diagnóstico sem expor segredos ou informações internas.
