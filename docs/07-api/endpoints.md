# Endpoints

Este documento será preenchido durante a especificação da API.

Exemplos conceituais:

```text
POST   /auth/login
GET    /customers
POST   /customers
GET    /vehicles
POST   /vehicles
GET    /vehicles/:id/positions
POST   /vehicles/:id/commands
GET    /billing/invoices
POST   /billing/payments
```

Os endpoints definitivos serão derivados dos casos de uso e do modelo de domínio.
