# Manutenção

Problemas podem ser investigados por:

- consulta do status;
- envio de comandos;
- verificação de comunicação;
- análise de eventos;
- análise de histórico.

Quando o problema for físico, o operador poderá orientar a substituição do equipamento.

O histórico de manutenção deve permanecer associado ao veículo/dispositivo conforme as relações históricas do domínio.
