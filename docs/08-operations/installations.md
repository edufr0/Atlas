# Instalações

O cliente pode:

- possuir equipamento próprio;
- adquirir equipamento recomendado;
- utilizar equipamento disponibilizado pela empresa.

A instalação pode ser feita por:

- técnico da empresa;
- parceiro;
- autoelétrica;
- outro instalador autorizado.

A instalação deve registrar veículo, dispositivo, responsável, data, status e observações.
