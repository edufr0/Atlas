# Control Plane

O Control Plane é o núcleo de gestão da ATLAS.

## Responsabilidades

- tenants;
- autenticação;
- autorização;
- clientes;
- usuários;
- veículos;
- dispositivos;
- SIM cards;
- billing;
- notificações;
- auditoria;
- branding;
- provisionamento;
- gerenciamento de ambientes.

O Control Plane não deve depender de lógica específica de um único rastreador.
